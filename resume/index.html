RnR: causal discovery from noisy, slowly sampled time series (NeurIPS 2026)

  • Built RnR, a solver that takes the output of standard causal-discovery methods and corrects the errors slow sampling introduces (indirect influences that appear direct); raised edge F1 by 45% over four widely used methods.
  • Weights each input edge by reliability, so contradictory inputs yield the closest consistent causal graph instead of a failure; solved exactly, with a staged search that keeps runtime practical.
  • Applied it to brain-imaging time series from 311 subjects (patients vs. controls) with collaborators at Yale and the University of Virginia: found more directed group-difference connections than five standard methods, and tighter preprocessing raised cross-subject reproducibility (Jaccard overlap) from 0.31 to 0.46.
  • Audited the solver pipeline end to end, found and fixed silent correctness bugs, and added unit tests and a regression checklist that every new analysis pipeline must pass.

Transformers for causal discovery from slowly sampled time series (paper in preparation)

  • Trained a transformer on ~1M simulated multichannel recordings to score directed links directly from slowly sampled data (AUROC 0.71–0.77 across sampling rates); trained on A100/H100 GPUs via SLURM.
  • Built an evaluation harness that requires every model to beat a no-data baseline and shuffled-time controls; it caught a data-leakage bug in a synthetic benchmark before any result was reported.

LLM-guided selection among equivalent causal graphs (ongoing)

  • Fine-tuned open-weight LLMs (Mistral-7B, Llama-3-8B; LoRA/QLoRA with Hugging Face PEFT) to choose the true causal graph among candidates the data alone cannot distinguish, using chain-of-thought reasoning and domain knowledge; built the simulator-backed training set and the benchmark (selection accuracy, edge F1).

Scalable causal discovery and multi-source integration

  • Scaled causal graph learning from the 6-node ceiling of prior exact methods to graphs with 100+ nodes by decomposing each graph into its strongly connected components, so cost grows linearly with their number.
  • Co-developed ION-C, which merges datasets that each measure a different subset of variables into one consistent causal graph; proved correctness and completeness and scaled from 4–6 to 25+ nodes.

Exact causal discovery under an unknown sampling rate (GRACE-C, ICLR 2023; CLeaR 2023)

  • Reformulated the problem as a constraint-satisfaction program for an off-the-shelf solver, cutting runtime from 17 hours to 6 seconds; proved correctness and completeness and matched the provably correct baseline on 1,000 test graphs.
  • Co-developed theory showing that the choice of sampling interval, including mixing two sampling rates, can shrink the set of causal models consistent with the data by up to 10,000×: how you sample determines what you can identify.
  • Released the methods in the lab's open-source gunfolds package (PyPI) with CI/CD and documentation.
